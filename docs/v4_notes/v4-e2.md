# E2 notes (Excel workbook, exporter)

## Pipeline (re-runnable at any time)
```
cd /home/vscode/IMPORTANT
make -j6 HEADLESS=1 CXX=zcxx CC=zcc OBJ=build/obj-e2 APP=build/ts-e2 TESTS=build/tests-e2 build/tests-e2
CORE=$(find src -name '*.cpp' | grep -v -e '^src/main.cpp' -e '^src/app/' -e '^src/rendering/')
zcxx -std=c++17 -O1 -Isrc -Iinclude $CORE src/app/DocExport.cpp tools/export_docs_main.cpp -o build/export_docs-e2
./build/export_docs-e2 build/scene_export.json          # ~8 s (includes a 130 s headless Scene run + effect census)
./build/tests-e2 build/test_results.json
uv run --with openpyxl --with pillow --with pypdf python tools/build_workbook.py      # ~15 s
uv run --with openpyxl --with pillow --with formulas python tools/verify_workbook.py formulas   # or LibreOffice / Excel if present
```
`make docs` (supervisor's Makefile) calls `python tools/build_workbook.py`; it needs openpyxl + pillow (+ pypdf for the audit
sheet's proposal-text check, optional).

## Exporter (src/app/DocExport.cpp, schema_version 3)
New top-level keys: `objects` (per final object: parts, groups, primitive mix), `roots` (per scene root incl. depth-1
`sections`), `controllables` (index, key, name, controls, possessable, root, parts, groups, animated nodes, primitive mix,
status text, chase / sight camera hints, `specs` = public constexprs read through the class headers, `moving_parts` = every node
with `animation` text), `walkspace` (floors, walls, indoor volumes), `layout` (BaseLayout.h), `combat.constants` (Combat.h,
DroneController.h, Uav.h, Scene.h) + `keep_out_box` (same expression as Scene.cpp), `effects` (MEASURED: a real `Combat` is run
at 60 Hz for explosion power 1.0 / 1.6 / 0.15, muzzle flash, dust, 1 s of burn; particle count per type, life and radius range,
peak, seconds until empty), `practical_lights` (47), `simulation` (a second `Scene` is stepped 130 s at 30 Hz: intruder entry
times, forced destruction of intruder 0 at t = 40 s -> Wreck -> Gone -> Alive timestamps, one `launchRound()` and the measured
10 s reload).
Components now include all roots (base, 3 rovers, tank, helicopter, AA gun, radar, gate, windsock, flag ...): 3 199 nodes, 2 983
leaves at the time of writing.

## Verification (tools/verify_workbook.py)
- LibreOffice / Excel (if present) recalculate the full workbook. Without them the pure-Python `formulas` engine runs on a
  REDUCED workbook built by the same code (`build_workbook.py --leaves 2 --groups 8`: all sheets complete, sheets 4 / 5 with 120
  rows) because the engine cannot digest the ~43 000 matrix formulas (it exceeded 8 GB / 15 min). In addition every one of the
  3 275 components is checked numerically in Python (M from S/R/T, world = parent x M) against the exported matrices.
- Last result: 0 formula errors, 0 flagged cells, |Excel - code| 1.7e-5 (float32 round-off, tolerance 1e-4), RESULT PASS.
- Quirk found: the `formulas` engine miscounts COUNTIFS for some IDs (T01, T126 returned 2); test lookups use SUMPRODUCT.
- Node ids are made unique by the exporter (the three rovers share ROV-xx ids: "#2", "#3" suffix) - needed for the parent lookups.
