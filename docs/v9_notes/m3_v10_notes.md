## 1. Primitive library (16)

New generators in `src/primitives/` (MeshData position + normal, indexed, CCW front faces, outward unit normals, every
one inside the unit cube [-0.5, 0.5]^3, so all unit-box paths stay valid):

| file | primitive | axis / placement in the unit cube |
|---|---|---|
| Hemisphere.h/.cpp | dome + base disc: upper half of the ellipsoid centred (0,-0.5,0), semi-axes (0.5, 1, 0.5) | pole +Y, base y = -0.5 (S = width x height x depth) |
| Torus.h/.cpp | torus(R, r, u, v), R + r = 0.5 | axis Z (like the cylinder), z in [-r, r]; `lib::torusScale(d, h)` gives S |
| Wedge.h/.cpp | triangular prism, 18 V / 8 T, flat faces | triangle in (y, z) extruded along X, slope faces +Y+Z, high side -Z |
| TaperedBox.h/.cpp | bottom 1 x 1, top topX x topZ | Y up |
| Pyramid.h/.cpp | square base, apex (0, 0.5, 0) | Y up |
| Capsule.h/.cpp | cylinder r 0.5 + half-ellipsoid caps of height h (hemispherical in the part when S.z h = S.x / 2) | axis Z |
| Annulus.h/.cpp | flat ring, inner radius parameter, both faces (separate vertices) | XY plane, normals +-Z |
| Helix.h/.cpp | circular tube swept along c(t) = (R cos 2pi k t, R sin 2pi k t, L (t - 0.5)), L = 1 - 2r, closed by end discs | axis Z |
| GrassBlade.h/.cpp | the existing v9 blade strip moved out of rendering/Grass.cpp (Grass.cpp now calls it), plus the per-quality blade budgets | 1.25 wide by design |
| Revolve.h/.cpp | shared surface-of-revolution builder (hemisphere, capsule) | |

| Library.h/.cpp | the 16 entries in report order, the scene parameter set (`lib::k...`), `sceneMesh(type)`, `kMeshTypes`, `isCuboidScale` | |

Cube vs cuboid: a cube-mesh part counts as cube when its S is uniform, else as cuboid, so the instances of the 16 entries
partition the scene's leaves (the sum equals `leaf_count`; T426). The grass blade has no leaves; its GPU instances are in
`gpu_instances` / `gpu_instances_by_quality`.

Integration: `PrimitiveType` gained Hemisphere, Torus, Wedge, TaperedBox, Pyramid, Capsule, Annulus, Helix, GrassBlade
(appended; old values unchanged), `primitiveName()`, `isLibraryPartPrimitive()`. Renderer and Frame Explorer upload
`sceneMesh(t)` for every `kMeshTypes` entry; `primitiveColor()` has a diagnostic colour for each; `specularLod()` knows the
curved ones. `SceneNode::restScale` added (see export).

Occlusion (ai/Occlusion.cpp): hemisphere exact (mapped onto the upper half of the r = 0.5 sphere), wedge / tapered box /
pyramid exact (Cyrus-Beck against their face planes read from the scene meshes), capsule / torus / annulus / helix
conservative (bounding cylinder). Ray tracing (raytrace/SceneBridge.cpp, analytic tracer unchanged): hemisphere traced
as its parent ellipsoid (`SceneBridge::tracedWorld`, the lower half sits inside the part it rests on), capsule / torus /
annulus as their bounding cylinder, wedge / tapered box / pyramid as their unit box, helix kept as a prim but always
hidden (thin wire; a solid cylinder would read as a drum).

Decisions:
- Concertina: one helix per coil position (5 turns, centre-line radius 0.38 m, 0.84 m long, wire 4 cm) instead of 6
  straight struts forming one hexagonal turn; no test checks the strut count and one coil per position is the natural
  part. "Razor strand" cylinders stay.
- Torus parts keep outer diameter and thickness (S.z = thickness / (2 r)); the tank hub covers the tyre's hole.
- Hemispheres: berm = upper half of the old ellipsoid (base at the old centre); radome sits on the mast top (1.85 m) with
  the sphere's old top (2.45 m); helmet keeps width / depth and crown height, base 2.5 cm below the old equator (deeper,
  reads as a helmet).
- Wedges: glacis = solid under the 27 deg slope (slope face where the plate's upper face was); ramp floor = solid ramp
  whose slope face is the walking surface; ammunition bunker wing slope = wedge against the core (0.65 m base, 1.3 m high).
- Tapered box (top 0.8 x 0.8): turret body (same S); soldier torso upside down (roll 180, shoulders wide), S
  0.38 wb x 0.33 x 0.23 (slightly smaller than the old ellipsoid because a box fills its bounds).
- Capsules for all sandbags with the old S; "Sandbag course" (0.1 x 0.1 x 2.8 m strips on the tower) stays a cylinder (the
  shared capsule mesh would give it 0.7 m long rounded ends).
- Pyramid: gate post cap, same 0.85 m base, 0.3 m high, bottom where the old cap's was.
- Annulus: UAV pad ring (inner / outer 0.86); the darker centre disc is unchanged.
- Materials, heat values and occluder / obstacle flags of every replaced part are unchanged (same Material and flag calls).

## 3. Export (`ts --export-docs FILE`, src/app/DocExport.cpp, schema_version 8)

- `primitives`: 16 entries (id P01..P16, number, name, type, function = generator call, vertices, indices, triangles,
  bytes, instances, `mesh_instances` (cube), `gpu_instances` (grass), `params` (JSON object), `formula_V`, `formula_T`,
  `parametric`, `axis`, `flat`, `example_part` {id, name, object, S}; flat ones (cube, cuboid, wedge, tapered box,
  pyramid) add `corners` (unique positions in generator order) and `faces` (corner index tuples, CCW from outside).
- components: `S_rest` (modelled scale; `SceneNode::restScale` for parts animated to zero scale: AA gun shell casings and
  flash, tank flash, helicopter blur discs and searchlight), `hidden_at_export`, `dfs_index` (global pre-order),
  `rig_root_id`, `rig_leaf_order` (leaf index in its rig's depth-first order), `part_kind`.
- objects: `rigs`, `rig_parts`, `variant_of` (family of numbered variants), `instances` (rigs in the family: 8 soldiers,
  3 tanks, 2 UAVs, 6 rovers), `build_stages` [{pct, parts}] for 12 / 35 / 65 / 100 %.
- Shared definitions: src/scene/PartOrder.h/.cpp (rigRoot, rigLeavesDfs, buildStageCount = ceil(pct N / 100),
  restScaleOf, hiddenAtRest, partKindName, partKinds, objectFamily, slug).

## 4. Capture modes (src/app/CaptureParts.h/.cpp, hooked in App::captureMode)

All at 10:30 after 2 s of simulation, exposure 2 (as the hero shots), 8 TAA frames, auto exposure off (one exposure per
set), quality ULTRA unless --quality. Commands (run from the repo root, headless, RTX 4070 via D3D12):

```
./build/ts-m3 --headless --capture OUT --only "prims,parts:Autonomous UAV,parts:Main Battle Tank,parts:Soldier 1,parts:Command Bunker,parts:Ammunition bunker,build:Autonomous UAV,build:Main Battle Tank,build:Soldier 1,build:Command Bunker,build:Ammunition bunker"
```

(one run, 400 PNGs, about a minute). Outputs:
- `OUT/parts_<slug>/NN_<part>.png` (512 x 512) + `index.json` (number, part, primitive, count, S_cm, R_deg, first_id,
  note). Part kinds = (name without side / index suffix, primitive) in hierarchy order of their first leaf; each tile is
  the first leaf with its own R and S_rest only, normalised so its bounding sphere fills 70 % of the tile; translucent
  parts are drawn opaque and the beam frustum as a solid (noted in index.json). Kinds: UAV 33, tank 75, soldier 48,
  command bunker 169, ammunition bunker 23 (files in the index).
- `OUT/build_<slug>_<pct>.png` (1600 x 1200, pct 12 / 35 / 65 / 100) + `build_<slug>.json`: the hero camera of the iso_*
  shots fitted to the whole rig, the first ceil(pct N / 100) parts in depth-first order visible; other rigs of the same
  object name (2nd UAV) hidden.
- `OUT/prims/prim_NN_<name>.png` and `_wire.png` (800 x 800) + `prims.json` (V, T, formulas, S, note): unit size, same
  camera; triangle edges overlaid on the CPU with hidden-line removal against a depth buffer of the same mesh (hidden
  edges faint). The cuboid is shown with S (1, 0.45, 0.7), the capsule with S (0.5, 0.5, 1) (hemispherical caps), the
  terrain disc scaled into the unit cube with heights x4 and its wire overlay drawn from createTerrainDisc(13, 48).

Contact sheets of these runs: `docs/v9_notes/m3_v10/prims_solid_sheet.jpg`, `prims_wire_sheet.jpg`,
`build_sheet_<object>.jpg` (12 / 35 / 65 / 100 % in reading order), `parts_sheet_<object>.jpg` (first 60 tiles).

`TS_TEST_ONLY=V10M3 ./build/tests-m3` runs one group (added to tests/test_main.cpp for quick iteration).

Existing expectations changed (all because a part now uses a library primitive other than cube / sphere / cylinder /
cone; the intent of each check is kept):
- T38 (test_main `isLabPrimitive`), T67 (bunker), T70 (base), T96 (helicopter `countLeaves`), T150 (camp), T201
  (soldier): "lab primitives only" now accepts every library part primitive (`isLibraryPartPrimitive`).
- T68 (bunker): the ramp probe samples the wedge's slope face (y + z = 0 in unit space) instead of the old slab's top
  face; still within 3 cm of the walk floor.
- T276 (ray tracing): dynamic prims are compared with `SceneBridge::tracedWorld(leaf)` (= leaf->world except a
  hemisphere's parent ellipsoid) instead of leaf->world.
