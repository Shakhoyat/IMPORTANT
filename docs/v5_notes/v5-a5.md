## API (ts::audio::AudioEngine)
startDevice() (false silently if no device; MA_NO_NULL so headless = false) / stop();
update(scene, listenerPos, forward, up, dt); pollEvents(scene); renderOffline(seconds, out) (exact length, fractional
remainder carried); render(float* interleaved, frames); setMasterVolume; setAmbientEnabled; prewarm();
lower level: setListener, handleEvent(GameEvent), playClip(Clip, pos, spatial, gain, power),
setSource(Loop kind, index, pos, vel*, param, dt) + endFrame(dt) (continuous sources not refreshed in a frame fade out).
`setSource(Loop::Drone, 1, pos, &vel, speed, dt)` is how a second UAV is added: update() currently only feeds
`scene.drone` (the squad API was not in Scene.h when written). Also Wav.h: makeWav16 / writeWav16 / WavWriter.

## Techniques (all 48 kHz float, seeded, deterministic)
- Drone hum: 4 detuned rotors x 6 blade-pass harmonics (h^-1.3), f = 105 + 7 v Hz, slow wobble, band-passed noise at 1.8 kHz; speed smoothed 50 ms.
- Helicopter: blade slap train at 25 Hz x rotor fraction (55 Hz decaying sine + LP noise click, random amplitude), 2.4 kHz turbine whine, LP noise. Rotor % parsed from status() "ROTOR n%".
- Tank: firing-pulse train 16 Hz + 3 Hz per m/s through 300 Hz LP, 130 Hz noise with tremolo, track clatter (HF impulses) when driving. Speed parsed from status() "SPEED x".
- Rounds in flight (missile motor roar / shell whistle): noise band-passes, Doppler-shifted; tracked by matching positions between frames (max 6).
- Launch whoosh: SVF band-pass noise Q 1.4, centre 350 -> 2750 Hz (rise 30 %) then fall, plus decaying random crackle.
- Explosion(power = value/100): HP crack (6 ms) + grit, sine boom 100 -> 30 Hz, noise body through a closing SVF low-pass (4 kHz -> 250 Hz), 90 Hz rumble tail with 7 Hz tremolo; length 2 + 1.5 p s (max 7), peak = 0.3 + 0.45 sqrt(p), tau scale with p -> energy grows with power.
- Cannon: crack + 95 -> 42 Hz boom + body + tail. Gatling: 1.4 s, 55 shots/s with spin-up and jitter, each shot = HP click + 150 Hz thump, 310 Hz motor whirr.
- Door: 70 Hz saw-harmonic motor + whine + noise ramping up/down, then clunk (55-70 Hz boom, noise tick, 430/790 Hz ring).
- Siren 650-1000 Hz triangle sweep (2.4 s period, 6 s), breach klaxon 820/610 Hz. Radio: lock = 2 x 1250 Hz beeps, confirm = 900 -> 1900 Hz chirp, kill = 880/1175/1568 Hz notes. Radio sounds are not spatialised.
- Ambient bed: gusting wind (3 slow LFOs drive SVF centre 250-600 Hz and level), 7 crickets (4.3-5.2 kHz, 3-pulse chirps at 29 ms, on/off trains, fixed pans), 50 Hz generator hum panned right.
- Spatial: pan = dot(dir, right) (faded to centre inside 1 m), equal-power cos/sin law; gain = ref/max(d, ref) (ref: drone 4 m, heli 8, tank 6, explosion 25, cannon 12, gatling 8, whoosh 5, door 4, siren 12); air absorption one-pole cutoff 16 kHz*exp(-d/90) (min 1.2 kHz); Doppler = 0.5 x physical, clamped 0.9..1.1; listener velocity from camera motion (ignored above 40 m/s = cut).
- Mixer: pool of 24 voices (one-shots + continuous), steal the quietest (a new sound quieter than all is dropped), per-voice gain smoothing (about 10 ms), master volume then tanh soft limiter with ceiling 0.88 (-1.1 dBFS), NaN-safe. One mutex protects voices (update on game thread, render on device thread); clips are synthesised and cached outside that lock.

## Record.cpp
Per rendered frame: after every 60 Hz step `pollEvents(scene)` (scene.events() only keeps the last step), then after
applyCinematic `update(...)` with the camera from `camera_.compute()` (forward = -view row 2, up = row 1) and
`renderOffline(1/fps)`, streamed to `<out stem>_audio.wav` (WavWriter, 16-bit). Video goes to `<stem>_noaudio.mp4`; at
the end `ffmpeg -y -loglevel error -i noaudio -i wav -c:v copy -c:a aac -b:a 192k -shortest out.mp4`, then the temp files are deleted. If the mux fails the silent
video is copied to `out` and the temp files kept. Without ffmpeg the WAV is still written next to the PNG frames. Env `TS_NO_AUDIO=1` = old silent behaviour. Encoder options unchanged.
NOT yet run end-to-end: Scene.cpp did not compile (supervisor editing Scene.h / uav_) when I tried to link the app. The
mux command itself was verified on a test video + build/audio_demo.wav (h264 + aac, both 10.0 s).

## Demo check (tools/audio_demo.cpp -> build/audio_demo.wav, build/audio_demo_spectrogram.png)
`zcxx -std=c++17 -O2 -Isrc -Iinclude tools/audio_demo.cpp src/audio/{AudioEngine,Synth,Spatial,Wav,Device}.cpp -ldl -lpthread -o build/audio_demo`

Result: RMS -22.0 dBFS, peak -4.46 dBFS (< -1 dBFS, no clipping). Per-second RMS: ambient only about -32 dB, launch -23, explosion -17, siren -21.
Spectrogram (0-8 kHz): cricket pulse dots at 4.3-5.2 kHz throughout, lock tone beeps (1.25 kHz + 2.5 kHz harmonic) at 3 s, broad whoosh noise 3.5-5 s, the explosion crack as a vertical line at 5 s with the low boom, kill chirps, siren triangle sweep with 3rd / 5th harmonics from 7 s, drone harmonic lines at the bottom.

## App integration (supervisor; App.cpp / App.h are H5's)
App.h: `#include "audio/AudioEngine.h"` and member `audio::AudioEngine audio_;`
Interactive start (not headless, e.g. after initWindow): `if (!headless_) audio_.startDevice();`
Each frame, after the scene step(s) and once the camera view `cam` (CameraView) is known (e.g. in renderFrame after `camera_.compute`):
```cpp
const Vec3 fwd{-cam.view.at(2, 0), -cam.view.at(2, 1), -cam.view.at(2, 2)};
const Vec3 up{cam.view.at(1, 0), cam.view.at(1, 1), cam.view.at(1, 2)};
audio_.update(*scene_, cam.position, fwd, up, frameDt);   // frameDt = real frame time
```
If several scene steps run per displayed frame, call `audio_.pollEvents(*scene_)` after each step too (dedupe makes the extra update() call safe). Pause: `audio_.setMasterVolume(paused_ ? 0.f : 1.f)`. Capture mode needs nothing (silent). Link needs -ldl -lpthread (already in LDFLAGS; Windows needs nothing extra).
