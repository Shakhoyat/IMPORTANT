# v5 F2 - lab figures rendered by the program

Command (fresh simulation, independent of the other shots; ~2 min total on llvmpipe):
`LP_NUM_THREADS=8 ./build/ts-f2 --headless --capture report/figures_lab --only lab_reflect,lab_buffers,lab_materials,lab_shading,lab_relief,lab_cv`
(an --only list made only of lab_* names selects just those shots). PNGs were afterwards re-compressed with a stdlib zlib script (the program's writer stores uncompressed). All PNGs <= 1600 px wide (save() downsizes).

- src/app/CaptureLab.{h,cpp} (new): lab::materials/shading/relief/reflections/buffers/cvFrame/cvStrip/writeCaptions.

- SUPERVISOR-OWNED EDITS (minimal, as allowed): ShaderSources.cpp `uniform int uBumpOff;` + `uBumpOff == 1 ||` in surfaceBump(); Renderer.cpp setFrameUniforms `sh.set("uBumpOff", s.bumpOn ? 0 : 1);`. Default 0 keeps relief on everywhere else.

## Limits
- Item 6 (vertex-colour interpolation) skipped: Vertex has no colour attribute; F1 does it in Python.
- SSR difference is subtle in the road view (road reflects mostly the dark sky and the floodlight); the reflectivity buffer shows where it acts.
- Relief figure: the stage backdrop shows a black band for y < ~0 (the renderer darkens below the world floor level), so slabs were raised; shadows and SSAO are off there. In the material grid the backdrop shows soft shadows of the spheres.
- Near moon cascade covers only 0-14 m of the view, so it is partly empty in the overview camera.
- CV: UAV 2's blob is tiny (4 px at 23 m) - the montage for UAV 2 shows it honestly.
