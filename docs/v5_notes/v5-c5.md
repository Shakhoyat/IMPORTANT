### Controls
Both: \ (actionPressed) stow <-> ready; arrows / mouse turn + elevate (ready only); ENTER (firePressed) launch. Slews use a trapezoid velocity profile (v = min(vmax, sqrt(2 a d)), a-limited).
SAM: turntable +-170 deg (22 deg/s, 55 deg/s^2), elevation 0..60 (14 deg/s, 35 deg/s^2; 0 -> 45 in 3.6 s), fire needs EL >= 5; one canister per press, cap hidden, round slides
out (8 + 60 t m/s, 2 s), Combat::muzzleFlash + emitDust (muzzle, back-blast, trail); canister reloads 8 s after its launch. Status "SAM-1  AZ 120  EL 45  READY 3/4  RELOAD 5S".
MLRS: mount +-165 deg (18 deg/s), elevation 0..55 (12 deg/s), 12 tubes (6 x 2); ENTER = ripple of all loaded tubes, 0.25 s apart (first at once, 2.75 s total),
flash + smoke per tube, 6 rocket nodes pooled; reload 15 s after the last tube. Status "MLRS-1  AZ 045  EL 35  RIPPLE 7/12" / "READY 12/12".
Hierarchy: root -> Trailer / Truck (static) ; Turntable / Mount (yaw) -> Cradle / Pod (pitch) -> canisters / tubes; hydraulic ram (cylinder + rod) re-aimed every frame.
Camera: chase behind the aim direction, sight = along the canister axis (fov 32, reticle).
