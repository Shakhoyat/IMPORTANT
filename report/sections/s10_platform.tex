\section{Platform, Build and Running on the RTX 4070}\label{sec:platform}
The source is C++17 with GLFW (window) or EGL (headless), GLAD (OpenGL 3.3 core loader) and no other library. The Makefile defines the
targets \code{all} (application and tests), \code{test}, \code{docs} (export, tests, workbook), \code{run} and \code{clean}; variables
\code{HEADLESS=1}, \code{CXX}, \code{CC}, \code{OBJ}, \code{APP} and \code{TESTS} select the build.

\paragraph{Test binary.} The tests link only the CORE sources (no \code{src/app}, no \code{src/rendering}, no GL): the whole simulation, planner,
combat and walk logic is unit-testable without a GPU. Each area has its own file with the \code{TS\_TEST\_GROUP} macro of
\code{tests/TestKit.h}; id ranges are T01--T55 (v1--v3 base), T60--T69 bunker, T70--T79 base, T80--T89 vehicles, T90--T99 air and sensors,
T100--T113 combat, T120--T129 application.

\subsection{Running on the RTX 4070 remote machine}
\begin{enumerate}
  \item \textbf{Windows remote.} Install MinGW-w64, run \code{build.bat} (or rebuild the executable with the cross-build script), then
  \code{run.bat -{}-fullscreen} or \code{run.bat -{}-quality epic -{}-size 2560x1440}. For remote desktop use Parsec or Sunshine + Moonlight, which capture the GPU output. Plain RDP often
  exposes only the Microsoft Basic Render Driver (software), so start the program from a console session or use the headless route.
  \item \textbf{Linux desktop.} \code{sudo apt install build-essential pkg-config libglfw3-dev}; \code{./build.sh \&\& ./run.sh -{}-fullscreen}. On hybrid laptops
  \code{\_\_NV\_PRIME\_RENDER\_OFFLOAD=1 \_\_GLX\_VENDOR\_LIBRARY\_NAME=nvidia ./run.sh}.
  \item \textbf{Linux headless over SSH.} Needs only the NVIDIA driver (EGL) and ffmpeg for video; \code{tools/remote\_setup\_linux.sh} installs everything and builds.
\end{enumerate}
The program logs \code{GL\_RENDERER} at start-up. If it says \code{llvmpipe}, \code{Mesa} or \code{Microsoft Basic Render Driver}, the NVIDIA driver is not in use.

\paragraph{FPS on the RTX 4070 has not been measured.} All captures and tests of this project were produced on a machine with a Mesa llvmpipe software renderer, where
a shot takes about one to two minutes (v4 brief); the only GPU numbers ever recorded are v2-era numbers from an AMD Radeon integrated GPU (Section~\ref{sec:results}). To obtain the RTX figures run, on the RTX machine:
\begin{center}\small
\code{ThermalSense -{}-headless -{}-quality epic -{}-benchmark build/benchmark.json}\quad (or without \code{-{}-headless} in a window)
\end{center}
and, for the 4K video, \code{ThermalSense -{}-headless -{}-quality epic -{}-size 3840x2160 -{}-fps 60 -{}-encoder h264\_nvenc -{}-record report/demo\_4k.mp4 60}.
The benchmark writes FPS and ms per frame for each preset, the cost of each feature by ablation, draw calls and per-pass GPU times; \code{tools/build\_workbook.py} then puts them in the workbook.

\paragraph{Capture shots.} \cli{capture} renders the shots of Table~\ref{tab:shots} at the sizes given in \code{Capture.cpp} (1920$\times$1080 for the v3/v4 set). Each shot sets its own time, camera
and flags; the v4 shots run after the director script has progressed, e.g. the strike shots are rendered at fixed delays after the impact so that each explosion phase is reproducible.
