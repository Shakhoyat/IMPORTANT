\section{Modelling transformations}
\label{sec:trs}
\here{2}
Each part's local matrix places a unit primitive: scale first, then rotate, then translate. In homogeneous
coordinates all three are $4\times4$ matrices, so one product gives the whole placement.

\begin{gather}
M = T(\vect t)\,R_y(\psi)\,R_x(\theta)\,R_z(\varphi)\,S(\vect s)\label{eq:trs}\\
T=\begin{bmatrix}1&0&0&t_x\\0&1&0&t_y\\0&0&1&t_z\\0&0&0&1\end{bmatrix},\
R_y=\begin{bmatrix}\cos\psi&0&\sin\psi&0\\0&1&0&0\\-\sin\psi&0&\cos\psi&0\\0&0&0&1\end{bmatrix},\
S=\mathrm{diag}(s_x,s_y,s_z,1)\nonumber
\end{gather}
\begin{equation}
\text{rotation about a pivot } \vect p:\quad M_{\text{pivot}} = T(\vect p)\,R\,T(-\vect p)
\label{eq:pivot}
\end{equation}
Order matters: $TRS\neq SRT$ (Figure~\ref{fig:d-trs}). Turret, gun, rotors and door hinges use Eq.~\eqref{eq:pivot}:
each sits in a group whose origin is the pivot. Figure~\ref{fig:trs-scene} shows the transforms at work in the base.

\begin{lstlisting}[language=C++,caption={The local matrix of every scene node (\code{src/scene/Transform.h}).}]
// Model matrix M = T * R * S with R = Ry * Rx * Rz: the primitive is scaled first,
// then rotated (roll, pitch, yaw), then translated.
Mat4 matrix() const { return translate(translation) * rotateEulerYXZ(rotationDeg) * ts::scale(scale); }
\end{lstlisting}

\textbf{All the matrices, as the code builds them.} The general forms of $T$, $R_x$, $R_y$, $R_z$ and $S$ are
Eqs.~\eqref{eq:basicTS} and \eqref{eq:basicmats} (Section~\ref{sec:decomp-mats}). Homogeneous coordinates let one $4\times4$ product hold both the linear part and the
translation:
\begin{gather}
\vect p=(x,y,z,1)^\top\ \text{(point: moved by } T),\qquad \vect d=(x,y,z,0)^\top\ \text{(direction: } T \text{ has no effect)}\nonumber\\
R=R_y(\psi)\,R_x(\theta)\,R_z(\varphi)\label{eq:homog}\\
N=\big(M_{3\times3}^{-1}\big)^{\!\top},\qquad \vect n_{\text{world}}=\frac{N\,\vect n}{\lVert N\,\vect n\rVert}\qquad\text{(normal matrix)}\label{eq:normalmat}
\end{gather}
\begin{itemize}
\item $M$ maps a tangent $\vect t$ to $M\vect t$; a normal must stay perpendicular, $(N\vect n)\cdot(M\vect t)=\vect n^\top N^\top M\vect t=0$
for every $\vect t$, so $N^\top M=I$ and $N=(M^{-1})^\top$. Under a non-uniform $S$ the plain $M\vect n$ tilts the normal
(Table~\ref{tab:normalmat}).
\item The renderer computes $N$ once per part on the CPU (\code{Math3D.cpp: normalMatrix}, a cofactor inverse) and sends it as
\code{uNormalMat}; the shaders only multiply.
\end{itemize}

\begin{lstlisting}[language=C++,caption={Rotation, Euler order and normal matrix (\code{src/math/Math3D.cpp}); no maths library is used.}]
Mat4 rotateY(float a) {                       // R_y: cos and sin in the x-z plane
    Mat4 r; const float c = std::cos(a), s = std::sin(a);
    r.at(0, 0) = c;  r.at(0, 2) = s;  r.at(2, 0) = -s;  r.at(2, 2) = c;
    return r;
}
Mat4 rotateEulerYXZ(const Vec3& e) { return rotateY(radians(e.y)) * rotateX(radians(e.x)) * rotateZ(radians(e.z)); }
Mat3 normalMatrix(const Mat4& model) {        // inverse-transpose of the upper-left 3x3
    const Mat4 inv = inverse(model);
    Mat3 n;
    for (int row = 0; row < 3; ++row)
        for (int col = 0; col < 3; ++col) n.m[col * 3 + row] = inv.at(col, row);
    return n;
}
\end{lstlisting}

\subsection{Following vertices into the world}
\label{sec:worked}
Four parts of the scene, followed by the same rule $\vect p_{\text{world}}=W\,\vect p_{\text{local}}$ with
$W=W_{\text{parent}}\,T\,R_y\,R_x\,R_z\,S$ (Eqs.~\ref{eq:trs}, \ref{eq:world}). The matrices are composed from each
part's $S$, $R$ and $T$ and reproduce its world matrix. The workbook sheet \code{Vertex\_Groups} holds the same groups as live formulas.

\textbf{A. A bunker wall panel: the 8 corners of a cuboid.} Part \wgAname, child of \wgAparent; its local
transform is $\wgAsrt$. The scale stretches the unit cube to the panel's size, the translation places it, and the
parent's matrix carries it into the world.

\textbf{C. Joints and doors: only one local matrix changes.} Walking changes the soldier's hip and knee angles
(rotations about the joint's $x$ axis, from the gait cycle of Section~\ref{sec:dynamic}); opening the blast gate
changes one rotation of each leaf group, $R_y(\mp\wgDoorSwing^\circ)$ about its jamb hinge: the group's origin is the
hinge, so its matrix $T(\vect p)\,R_y(\psi)$ is the pivot rotation of Eq.~\eqref{eq:pivot}. Every part below the changed
node moves with it, with no other matrix touched.

\textbf{Limitation.} Euler angles in a fixed order are easy to tabulate as a $T$/$R$/$S$ table but lock at
$\theta=\pm90^\circ$; the camera rig and the interpolation between simulation ticks therefore keep their rotations as
quaternions.
