\section{Modelling transformations}
\label{sec:trs}
\here{2}
\concept{Each part's local matrix places a unit primitive: scale first, then rotate, then translate. In homogeneous
coordinates all three are $4\times4$ matrices, so one product gives the whole placement.}

\begin{gather}
M = T(\vect t)\,R_y(\psi)\,R_x(\theta)\,R_z(\varphi)\,S(\vect s)\label{eq:trs}\\
T=\begin{bmatrix}1&0&0&t_x\\0&1&0&t_y\\0&0&1&t_z\\0&0&0&1\end{bmatrix},\
R_y=\begin{bmatrix}\cos\psi&0&\sin\psi&0\\0&1&0&0\\-\sin\psi&0&\cos\psi&0\\0&0&0&1\end{bmatrix},\
S=\mathrm{diag}(s_x,s_y,s_z,1)\nonumber
\end{gather}
\begin{equation}
\text{rotation about a pivot } \vect p:\quad M_{\text{pivot}} = T(\vect p)\,R\,T(-\vect p)
\label{eq:pivot}
\end{equation}
Order matters: $T R S \neq S R T$. Scaling after a rotation would shear a rotated box; translating before a rotation
would swing the part around the parent's origin. The turret, gun barrel, rotor and door hinges use
Eq.~\eqref{eq:pivot}: each sits in a group node whose origin is the pivot.

\begin{lstlisting}[language=C++,caption={The local matrix of every scene node (\code{src/scene/Transform.h}).}]
// Model matrix M = T * R * S with R = Ry * Rx * Rz: the primitive is scaled first,
// then rotated (roll, pitch, yaw), then translated.
Mat4 matrix() const { return translate(translation) * rotateEulerYXZ(rotationDeg) * ts::scale(scale); }
\end{lstlisting}

\subsection{Following vertices into the world}
\label{sec:worked}
Four parts of the scene, followed by the same rule $\vect p_{\text{world}}=W\,\vect p_{\text{local}}$ with
$W=W_{\text{parent}}\,T\,R_y\,R_x\,R_z\,S$ (Eqs.~\ref{eq:trs}, \ref{eq:world}). All matrices and points are computed by
\code{tools/v10/gen\_m3.py} from the exported $S$, $R$, $T$ of each part; the composition reproduces the exported world
matrices.

\textbf{A. A bunker wall panel: the 8 corners of a cuboid.} Part \wgAname, child of \wgAparent; its local
transform is $\wgAsrt$. The scale stretches the unit cube to the panel's size, the translation places it, and the
parent's matrix carries it into the world.

\textbf{B. A tank road wheel: turning a torus onto the axle.} The torus is generated around the $z$ axis; the
road-wheel group (\wgBname) turns it with $R_y$ so that the tyre's axis follows the hull's side, and the tyre's own scale
sets its radius and width: $\wgBsrt$.

\textbf{C. Joints and doors: only one local matrix changes.} Walking changes the soldier's hip and knee angles
(rotations about the joint's $x$ axis, from the gait cycle of Section~\ref{sec:dynamic}); opening the blast door
changes one translation of the leaf group by \wgDoorSlide\,m. Every part below the changed node moves with it,
with no other matrix touched.

\textbf{D. The UAV's camera: a yaw inside a pitch inside the airframe.} The thermal camera hangs under two gimbal

translations do not affect it).
