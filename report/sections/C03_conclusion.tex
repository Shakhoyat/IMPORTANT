\section{Conclusion}
\label{sec:conclusion}
ThermalSense takes a small set of unit primitives through every stage of the graphics pipeline and makes each stage
visible inside the running program. Table~\ref{tab:objectives} maps each objective to the section that proves it.

A 2-minute showcase video (1920$\times$1080, 60\,fps, EPIC) is rendered by the program itself with
\code{ts --record FILE 120}: night wave, UAV tracking and strikes, first-person views, the ray-tracing modes and the
day cycle. What is missing is listed honestly in Section~\ref{sec:limits}.
