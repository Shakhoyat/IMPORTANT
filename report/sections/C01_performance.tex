\section{Performance evaluation}
\label{sec:perf}
\textbf{Setup.} \code{TS\_BENCH\_V10=1 ts --headless --quality epic --size 1920x1080 --seed 1 --benchmark report/data/bench.json}:
the same orbit camera for every configuration; each configuration first settles (2\,s of simulation after a clock
change), then is timed in 3 interleaved rounds of 10\,s (30\,s per configuration). A frame includes the simulation
tick, both UAV camera renders, the main frame and the HUD. Mean and 95th-percentile frame times come from every timed
frame; draw calls include shadow passes. The program writes \code{bench.json.csv}, copied to \code{report/data/bench.csv}.
Headless runs use the RTX\,4070 through the WSL2 d3d12 driver, which is slower than the native Windows driver (v9 M0
measured 54--73\,fps headless against 80--101\,fps in the native exe on the same shots).
