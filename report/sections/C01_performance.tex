\section{Performance evaluation}
\label{sec:perf}
\textbf{Setup.} 1920$\times$1080, EPIC, seed 1, the same orbit camera for every configuration. Each configuration first settles for 2\,s of simulation after a clock change, then is
timed in 3 interleaved rounds of 10\,s. A frame includes the simulation tick, both UAV camera renders, the main frame
and the HUD. Mean and 95th-percentile frame times come from every timed frame; draw calls include shadow passes.
Headless runs use the RTX\,4070 through the WSL2 d3d12 driver, which is slower than the native Windows driver
(54--73\,fps headless against 80--101\,fps natively on the same shots).
