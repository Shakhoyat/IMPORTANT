\section{Reproducing the figures}
\label{app:repro}
Every number and image of this report is regenerated from the program and its scripts, in this order (the program
binary is \code{build/ts-f}, built with \code{make HEADLESS=1}; Python scripts need numpy, pillow, matplotlib,
openpyxl and pymupdf):
\begin{enumerate}\raggedright
\item Scene export and low-resolution primitives (GPU-free):\\
\code{ts --export-docs report/data/scene\_export\_v10.json}\\
\code{ts --export-prims-lowres report/data/prims\_lowres.json}
\item Program captures (RTX\,4070, 1920$\times$1080, EPIC, seed 1): \code{tools/v10/capture\_all.sh} (scene, lab, game,
ray-tracing and teaching shots) and \code{python3 tools/report/capture\_shapes.py} (shape views, cutaways, the camp
from the air, the munitions at one scale, build stages, the primitive gallery and part tiles); then
\code{tools/v10/prepare\_figures.py}.
\item Benchmark: \code{TS\_BENCH\_V10=1 TS\_BENCH\_ROUNDS=3 TS\_BENCH\_SECONDS=10 ts --headless --quality epic --size 1920x1080 --seed 1 --benchmark report/data/bench.json}
(writes \code{bench.json.csv}, copied to \code{report/data/bench.csv}).
\item Plots and diagrams: \code{tools/v10/plots.py}, \code{tools/v10/diagrams.py}.
\item Numbers and tables: \code{tools/report/gen\_prim\_colors.py} (colour key), \code{tools/v10/gen\_numbers.py},
\code{tools/v10/gen\_m3.py}, \code{tools/v10/gen\_game.py}, \code{tools/report/gen\_prim\_cards.py} (Section~\ref{sec:prims}
cards), \code{tools/report/gen\_designs.py} (Section~\ref{sec:decomp}).
\item Workbook: \code{tools/v10/build\_cg\_workbook.py}, \code{tools/v10/sheet\_to\_tex.py}, \code{tools/v10/gen\_wb\_appendix.py}.
\item Checks: \code{tools/report/check\_counts.py} (every count against the export) and \code{tools/report/lint\_prose.py};
then \code{tectonic main.tex} in \code{report/}.
\end{enumerate}
