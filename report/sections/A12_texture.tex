\section{Texture mapping}
\label{sec:tex}
\here{9}
A texture adds detail without geometry. A surface point gets coordinates $(u,v)$ (stored per vertex, or
computed from position), the texture is sampled there with filtering and mip-maps, and the result modulates a
material property. A procedural texture computes the value with a function instead of an image.
\begin{equation}
\text{bump: }\ \vect N'=\mathrm{normalize}\big(\vect N-\nabla h\big),\qquad
\text{mip level: }\ \lambda=\log_2\max\Big(\Big\lVert\tfrac{\partial(u,v)}{\partial x}\Big\rVert,\Big\lVert\tfrac{\partial(u,v)}{\partial y}\Big\rVert\Big)
\label{eq:tex}
\end{equation}
\textbf{The texture equations in the code.}
\begin{gather}
(u,v)=\begin{cases}(x,z) & |N_y|>0.7\\(z,y) & |N_x|>|N_z|\\(x,y) & \text{else}\end{cases}\quad\text{(box projection)},\quad
\text{noise}(\vect q)=\operatorname{lerp}\big(\operatorname{lerp}(h_{00},h_{10},s_x),\operatorname{lerp}(h_{01},h_{11},s_x),s_y\big)\label{eq:noise}\\
s=3f^2-2f^3,\quad f=\vect q-\lfloor\vect q\rfloor,\qquad
\operatorname{fbm}(\vect q)=\sum_{o=0}^{3}0.5^{\,o+1}\,\text{noise}\big(2.03^{\,o}\vect q+\vect c_o\big)\nonumber\\
\text{bump: } \frac{\partial h}{\partial u}\approx\frac{h(u+e)-h(u-e)}{2e},\ e=4\,\text{mm},\qquad
\vect N'=\operatorname{normalize}\Big(\vect N-k\Big(\frac{\partial h}{\partial u}\vect T+\frac{\partial h}{\partial v}\vect B\Big)\Big)\nonumber
\end{gather}
\begin{gather}
\text{bilinear: } c=\operatorname{lerp}\big(\operatorname{lerp}(c_{00},c_{10},\alpha),\,\operatorname{lerp}(c_{01},c_{11},\alpha),\,\beta\big)\label{eq:filter}\\
\text{trilinear: } c=\operatorname{lerp}\big(c_{\lfloor\lambda\rfloor},\,c_{\lfloor\lambda\rfloor+1},\,\lambda-\lfloor\lambda\rfloor\big)\nonumber
\end{gather}
\begin{itemize}
\item $h_{ij}$: an integer hash of the lattice corner (\code{latticeHash}, a 32-bit mix), the same on every \ab{523}{GPU} and on the
\ab{524}{CPU} mirror; $\vect c_o$: a fixed offset per octave; $k$ fades the relief from 12 to 40\,m.
\item Box projection picks the plane of the largest normal component, so a primitive needs no stored $(u,v)$ and a
pattern never stretches; it is used for the albedo patterns (\code{surfaceAlbedo}) and the relief (\code{surfaceBump}).
\item Image textures (imported trees, the ground map, the font) are mip-mapped by the \ab{525}{GPU}: \code{glGenerateMipmap} builds the
box-filtered levels and \code{GL\_LINEAR\_MIPMAP\_LINEAR} selects $\lambda$ of Eq.~\eqref{eq:tex} and blends as in
Eq.~\eqref{eq:filter}. This lookup is fixed-function; the procedural patterns are the project's own code.
\end{itemize}
\begin{lstlisting}[language=C++,caption={Value noise and its fractal sum (\code{src/rendering/ShaderSources.cpp}, OpenGL Shading Language).}]
float valueNoise(vec2 p) {
    vec2 i = floor(p), f = fract(p);
    f = f * f * (3.0 - 2.0 * f);                       // smoothstep fade
    float a = latticeHash(i), b = latticeHash(i + vec2(1, 0)), c = latticeHash(i + vec2(0, 1)), d = latticeHash(i + vec2(1, 1));
    return tsMix(tsMix(a, b, f.x), tsMix(c, d, f.x), f.y);   // bilinear blend of the four corners
}
float fbm(vec2 p) {
    float s = 0.0, a = 0.5;
    for (int i = 0; i < 4; ++i) { s += a * valueNoise(p); p = p * 2.03 + vec2(17.1, 9.7); a *= 0.5; }
    return s;
}
\end{lstlisting}

A bump map perturbs only the normal (Eq.~\eqref{eq:tex}): the silhouette stays straight while the lighting shows
relief.

\textbf{Limitation.} Procedural world-space patterns need no \ab{526}{UV} unwrapping and never stretch, but they slide over a moving
part unless evaluated in object space, and they cannot be mip-mapped; aliasing of fine noise is left to \ab{527}{MSAA} and \ab{528}{TAA}.
