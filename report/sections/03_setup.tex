\textbf{Time scale.} In automatic mode one in-game day lasts \daySeconds{}\,s (\dayMinutes{} real minutes): 10\,s per
in-game hour by day, 13.3\,s per hour by night, and 1.5 times slower while the sun is within $6^\circ$ of the horizon
(\code{DayCycleConfig}). The clock can also be set or scrubbed by hand.

\textbf{Determinism.} The simulation runs at a fixed 60\,Hz tick and every random stream derives from the seed. A
recorded session replays bit for bit: test T404 records 60\,s with random input and variable frame times, replays it
from text, and all 60 per-second world hashes match.
