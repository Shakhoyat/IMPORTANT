\section{Primitives and geometry}
\label{sec:prims}
\here{1}
Every solid object in the scene is a hierarchy of instances of a few unit meshes centred at the origin. A mesh is a
vertex array (position and normal) and an index array (three indices per triangle). Each mesh is uploaded once and
drawn many times with different model matrices.

The library has sixteen generators (Table~\ref{tab:prims}). Every one fits the unit cube $[-\tfrac12,\tfrac12]^3$,
so a part's scale $S$ is its size in metres. Figure~\ref{fig:prims} shows the sixteen meshes and the whole camp
coloured by primitive; the same colour key is used in every figure, legend and table of this report.

\subsection{How a generator builds a mesh}
\label{sec:primverts}
Every generator makes the same three choices; the cards that follow show where each one matters.

\textbf{Shared or duplicated vertices.} A vertex carries one normal. On a curved surface the triangles around a vertex
should agree on that normal, so that Gouraud and Phong shading (Section~\ref{sec:shading}) interpolate a smooth
surface. The sphere therefore shares every vertex between up to six triangles and needs only \nSphereV{} vertices for
\nSphereTri{} triangles. At a sharp edge the two faces need different normals, so the corner is stored once per face:
the cube's 8 corners become $6\times4=24$ vertices, and a cylinder stores its rim twice, once with the side normal and
once with the cap normal.

\textbf{The seam.} A curved surface is a grid of parameters $(i,j)$ that wraps around: the column after $j=s-1$ is
column $0$ again. The generators index the wrap as $j \bmod s$, so the first column is reused and no vertex is
repeated along the seam (the red line in the drawings). The meshes carry no texture coordinates, so nothing forces a
split there.

\textbf{Winding.} Every triangle is listed counter-clockwise as seen from outside, so its geometric normal
$(\vect{b}-\vect{a})\times(\vect{c}-\vect{a})$ points outwards and back-face culling can drop the far side. Where a
generator mirrors half a mesh (the sphere's southern half), it swaps two indices of every mirrored triangle to keep this
order.

\textbf{The generator's equations (sphere, \code{primitives/Sphere.cpp: createSphere}).} With $r=0.5$, $s$ slices and
$k$ stacks ($k$ even), ring $i$ and column $j$:
\begin{gather}
\vect n_{ij}=(\sin\theta_i\cos\varphi_j,\ \cos\theta_i,\ \sin\theta_i\sin\varphi_j),\quad \vect p_{ij}=r\,\vect n_{ij},\quad
\theta_i=\frac{\pi i}{k},\quad \varphi_j=\frac{2\pi j}{s}\label{eq:spheregen}\\
\text{index}(i,j)=1+(i-1)s+(j\bmod s),\qquad \text{band quad }(i,j):\ (a_0,a_1,b_0),\,(a_1,b_1,b_0)\nonumber\\
V=s(k-1)+2,\qquad T=2s(k-1),\qquad V-E+T=2\quad (E=\tfrac32T)\nonumber
\end{gather}
\begin{itemize}
\item The normal of a vertex on a sphere is its position over $r$; on a cylinder side it is $(\cos\varphi,\sin\varphi,r_b-r_t)$
normalised (\code{Cylinder.cpp}), on a cap $(0,0,\pm1)$.
\item The flat shader ignores the stored normals and uses the face normal
$\vect n_f=\frac{(\vect b-\vect a)\times(\vect c-\vect a)}{\lVert(\vect b-\vect a)\times(\vect c-\vect a)\rVert}$ (Section~\ref{sec:shading}).
\item Euler's formula $V-E+F=2$ holds for every closed mesh with shared vertices; it is a check on the counts of Table~\ref{tab:prims}.
\end{itemize}
\begin{lstlisting}[language=C++,caption={The northern rings of the sphere and the index of a ring vertex (\code{src/primitives/Sphere.cpp}).}]
for (int k = 1; k <= half; ++k) {
    const float theta = PI * static_cast<float>(k) / static_cast<float>(stacks);
    for (int j = 0; j < slices; ++j) {
        const float phi = 2.0f * PI * static_cast<float>(j) / static_cast<float>(slices);
        const Vec3 n{std::sin(theta) * std::cos(phi), std::cos(theta), std::sin(theta) * std::sin(phi)};
        mesh.vertices.push_back({n * r, n});            // position = r * normal
    }
}
auto ring = [slices](int k, int j) { return static_cast<uint32_t>(1 + (k - 1) * slices + (j % slices)); };
\end{lstlisting}

\subsection{The primitive cards}
\label{sec:primcards}
Each card describes one generator. (a) is the scene mesh as the renderer draws it, with its triangle edges. (b) is
the same generator called with small parameters so that every vertex can be numbered: the grey dashed edges face away,
the dark cell is the one in (c), violet arrows are normals, orange arcs are the parameter angles and darker fans are
caps with their own vertices. (c) splits that cell into its two triangles in the order the generator emits them.
(d) gives the formulas and the vertex and triangle counts, and (e) shows three parts of the scene built on the
primitive. The flat primitives replace (b) with their corner drawing.
