\section{3D viewing transformation}
\label{sec:view}
\here{3}
The view matrix moves the world into the camera's frame. It is built from the eye $\vect e$, the point
looked at $\vect a$ and an up hint $\vect{up}$, by an orthonormal basis and a translation.
\begin{equation}
\vect n=\frac{\vect e-\vect a}{\lVert\vect e-\vect a\rVert},\quad
\vect u=\frac{\vect{up}\times\vect n}{\lVert\vect{up}\times\vect n\rVert},\quad
\vect v=\vect n\times\vect u,\qquad
V=\begin{bmatrix}u_x&u_y&u_z&-\vect u\cdot\vect e\\v_x&v_y&v_z&-\vect v\cdot\vect e\\n_x&n_y&n_z&-\vect n\cdot\vect e\\0&0&0&1\end{bmatrix}
\label{eq:view}
\end{equation}
The code writes the same matrix with $\vect f=-\vect n$ (forward), $\vect s=\vect u$ (side) and $\vect u=\vect v$
(\code{math/Math3D.cpp lookAt}); the camera looks down its $-z$ axis.
\begin{equation}
V=\underbrace{\begin{bmatrix}u_x&u_y&u_z&0\\v_x&v_y&v_z&0\\n_x&n_y&n_z&0\\0&0&0&1\end{bmatrix}}_{R_{uvn}:\ \text{rotate the axes onto } x,y,z}
\underbrace{\begin{bmatrix}1&0&0&-e_x\\0&1&0&-e_y\\0&0&1&-e_z\\0&0&0&1\end{bmatrix}}_{T(-\vect e):\ \text{eye to the origin}},\qquad
V^{-1}=T(\vect e)\,R_{uvn}^{\top}\label{eq:viewdecomp}
\end{equation}
\begin{itemize}
\item $R_{uvn}$ is orthonormal, so its inverse is its transpose; the camera's world matrix is $V^{-1}$, and a camera hung in
the scene graph (the UAV gimbal) uses $V=W_{\text{camera}}^{-1}$.
\item A point straight ahead of the eye at distance $d$ lands at $(0,0,-d)$ in eye space.
\end{itemize}
\begin{lstlisting}[language=C++,caption={The view matrix (\code{src/math/Math3D.cpp: lookAt}); $\vect s=\vect u$, $\vect u=\vect v$, $\vect f=-\vect n$ of Eq.~\eqref{eq:view}.}]
Mat4 lookAt(const Vec3& eye, const Vec3& center, const Vec3& up) {
    const Vec3 f = normalize(center - eye);       // forward = -n
    const Vec3 s = normalize(cross(f, up));       // side    =  u
    const Vec3 u = cross(s, f);                   // up      =  v
    Mat4 r;
    r.at(0, 0) = s.x;  r.at(0, 1) = s.y;  r.at(0, 2) = s.z;  r.at(0, 3) = -dot(s, eye);
    r.at(1, 0) = u.x;  r.at(1, 1) = u.y;  r.at(1, 2) = u.z;  r.at(1, 3) = -dot(u, eye);
    r.at(2, 0) = -f.x; r.at(2, 1) = -f.y; r.at(2, 2) = -f.z; r.at(2, 3) = dot(f, eye);
    return r;
}
\end{lstlisting}

The UAV camera of Figure~\ref{fig:cams}d takes its eye and axes from the gimbal nodes of Figure~\ref{fig:sg}: its
view matrix is the inverse of the camera node's world matrix.

\textbf{Camera system.} Orbit (default), free fly (\key{Home}), chase, UAV camera, walk, first and third person on
any soldier (\key{Tab}, \key{V}), UAV chase / FPV / gimbal, any moving object's point of view (\key{F4}) and the
cinematic director (\key{K}). Changes of camera blend over 0.6\,s on a critically damped spring.

\textbf{Limitation.} When $\vect{up}\parallel\vect n$ (looking straight down) the cross product vanishes. The top view of
Section~\ref{sec:proj} avoids this by using $\vect{up}=-\vect z$; the free camera clamps its pitch to $\pm85^\circ$.
