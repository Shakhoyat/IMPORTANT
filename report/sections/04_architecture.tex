An orthographic top view keeps distances true, so Figure~\ref{fig:layout} doubles as a scaled site plan.

\textbf{Frame loop.} Each frame: fixed 60\,Hz simulation ticks (scene, \ab{474}{AI}, combat, \ab{475}{UAV} cameras), render with
interpolation between the last two ticks, the \ab{476}{UAV} images' vision on a worker thread, \ab{477}{HUD}, present. Offline modes
(\code{--capture}, \code{--record}) run the same code with a fixed step.
