\textbf{Frame loop.} Each frame: fixed 60\,Hz simulation ticks (scene, AI, combat, UAV cameras), render with
interpolation between the last two ticks, the UAV images' vision on a worker thread, HUD, present. Offline modes
(\code{--capture}, \code{--record}) run the same code with a fixed step.
